How it works:
Each license key is cryptographically bound to a specific device's unique Machine ID. The key uses HMAC-MD5 with the app's secret salt, then formats it as GDCLIB-XXXX-XXXX-XXXX. Keys cannot be transferred between devices.

Validity: 365 days from activation date.
